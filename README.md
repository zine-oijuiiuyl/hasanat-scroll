# Hasanat Scroll

An endless scroll of dhikr, duas and ayat with a game score, a growing buddy, a learning path and a "Remove sins" counter. Works offline and can be added to the iPhone Home Screen.

The app's source is the Expo app in [mobile/](mobile/). The web version at the repo root (GitHub Pages) is built from it with `node mobile/scripts/build-web.js --deploy`, so the web page and the phone app are the same app.
